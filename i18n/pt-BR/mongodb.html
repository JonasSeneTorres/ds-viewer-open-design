Banco de dados de documentos. Marca da folha verde, foco em documentação para desenvolvedores.

Tema visual e atmosfera

O site do MongoDB é uma experiência de floresta profunda encontrando o terminal — um design system enraizado no preto-azulado mais escuro (#001e2b), que evoca ao mesmo tempo a densidade de um banco de dados e a profundidade da copa de uma floresta. Sobre essa tela quase preta, um verde neon marcante (#00ed64) pulsa como destaque da marca — vivo o bastante para parecer elétrico, orgânico o bastante para parecer vivo. Não é o neon frio do cyberpunk; é o verde bioluminescente de algo crescendo no escuro.

O sistema tipográfico é arquitetonicamente ambicioso: a MongoDB Value Serif nos enormes títulos do hero (96px) cria uma presença editorial e cheia de autoridade — tipografia serifada na escala de uma empresa de banco de dados é uma escolha ousada que diz "não somos só mais uma empresa de tecnologia". A Euclid Circular A faz o trabalho pesado do texto de corpo e da interface, com uma faixa de pesos incomumente ampla (300–700), enquanto a Source Code Pro é a fonte de código e rótulos, com tratamentos característicos em caixa-alta e espaçamento entre letras bem largo (1px–3px). Esse sistema de três fontes cria uma hierarquia que vai da elegância editorial → ao profissionalismo geométrico → à precisão de engenharia.

O que torna o MongoDB distinto é seu design de dois modos: um mundo escuro de hero/recursos (#001e2b com destaques em verde neon) e um mundo claro de conteúdo (branco, com bordas cinza-azuladas #b8c4c2). A transição entre esses modos cria um contraste dramático. O sistema de sombras usa sombras escuras tingidas de azul-esverdeado (rgba(0, 30, 43, 0.12)) que mantêm a atmosfera de floresta escura mesmo sobre superfícies claras. Os botões usam formato de pílula (raio de 100px–999px) com bordas em MongoDB Green (#00684a), e todo o sistema de componentes faz referência ao design system LeafyGreen.

Características principais:

  • Fundos em preto-azulado profundo (#001e2b) — escuro de floresta, não escuro de espaço sideral
  • MongoDB Green neon (#00ed64) como único destaque da marca — elétrico e orgânico
  • MongoDB Value Serif nos títulos do hero — autoridade editorial em escala de tecnologia
  • Euclid Circular A no corpo, com peso 300 (leve) como peso de corpo característico
  • Source Code Pro com espaçamento entre letras largo em caixa-alta (1px–3px) nos rótulos técnicos
  • Sombras tingidas de azul-esverdeado: rgba(0, 30, 43, 0.12) — as sombras carregam a cor da floresta
  • Dois modos: seções hero em azul-esverdeado escuro + seções de conteúdo brancas e claras
  • Botões em pílula (raio de 100px) com bordas verdes (#00684a)
  • Link Blue (#006cfa) com transição no hover para #3860be

Princípios

  • Serifa para autoridade: a MongoDB Value Serif em escala de hero cria uma presença editorial incomum em tecnologia — comunica que o MongoDB é uma instituição, não uma startup.
  • Peso 300 como padrão do corpo: a Euclid Circular A usa o leve (300) no texto de corpo, criando uma experiência de leitura arejada que contrasta com os fundos densos e escuros.
  • Rótulos monoespaçados com tracking largo: a Source Code Pro em caixa-alta com espaçamento entre letras de 1px–3px cria sinalizações técnicas que parecem rótulos de campos de banco de dados — sistemáticas, estruturadas, classificadas.
  • Faixa de quatro pesos: 300 (corpo leve) → 400 (padrão) → 500 (interface/navegação) → 700 (CTA em negrito) — uma faixa mais ampla que a da maioria dos sistemas, permitindo uma hierarquia refinada.

Estilo dos componentes

Botões

Verde primário (superfície escura)

  • Fundo: #00684a (verde MongoDB apagado)
  • Texto: #000000
  • Raio: 50% (circular) ou 100px (pílula)
  • Borda: 1px solid #00684a
  • Sombra: rgba(0,0,0,0.06) 0px 1px 6px
  • Hover: escala 1.1
  • Ativo: escala 0.85

Botão azul-esverdeado escuro

  • Fundo: #1c2d38
  • Texto: #5c6c75
  • Raio: 100px (pílula)
  • Borda: 1px solid #3d4f58
  • Hover: fundo #1eaedb, texto branco, translateX(5px)

Botão com contorno (superfície clara)

  • Fundo: transparente
  • Texto: #001e2b
  • Borda: 1px solid #b8c4c2
  • Raio: 4px–8px
  • Hover: tom de fundo

Cards e contêineres

  • Modo claro: fundo branco com borda 1px solid #b8c4c2
  • Modo escuro: fundo #001e2b ou #1c2d38 com 1px solid #3d4f58
  • Raio: 16px (padrão), 24px (médio), 48px (grande/hero)
  • Sombra: rgba(0,30,43,0.12) 0px 26px 44px (tingida de floresta)
  • Contêineres de imagem: raio de 30px–32px

Campos e formulários

  • Textarea: texto #e8edeb, padding de 12px 12px 12px 8px
  • Bordas: 1px solid #b8c4c2 no claro, 1px solid #3d4f58 no escuro
  • Raio dos campos: 4px

Navegação

  • Cabeçalho escuro sobre fundo preto de floresta
  • Euclid Circular A 16px peso 500 nos links de navegação
  • Logo do MongoDB (ícone de folha + logotipo) alinhado à esquerda
  • Botões CTA verdes em pílula alinhados à direita
  • Megamenus em dropdown com categorias de produtos

Tratamento de imagens

  • Capturas de dashboards sobre fundos escuros
  • Elementos de interface com destaque verde nas capturas
  • Raio de 30px–32px nos contêineres de imagem
  • Seções escuras em largura total para vitrines do produto

Componentes característicos

Sublinhados de destaque em verde neon

  • 0px 2px 2px 0px solid #00ed64 — borda inferior + direita criando sublinhados de destaque
  • Usados em títulos de recursos e texto realçado
  • Também aparecem na variante #006cfa (azul)

Sistema de rótulos em Source Code

  • Source Code Pro 14px em caixa-alta com espaçamento entre letras de 1px–2px
  • Usados como marcadores de categoria de seção acima dos títulos
  • Criam uma estética de "rótulo de campo de banco de dados"

Princípios de layout

Sistema de espaçamento

  • Unidade base: 8px
  • Escala: 1px, 4px, 7px, 8px, 10px, 12px, 14px, 15px, 16px, 18px, 20px, 24px, 32px

Grid e contêiner

  • Largura máxima do conteúdo centralizada
  • Seção hero escura com conteúdo contido
  • Seções de conteúdo claras abaixo
  • Grades de cards: 2–3 colunas
  • Rodapé escuro em largura total

Filosofia do espaço em branco

  • Transições dramáticas de modo: a passagem das seções em azul-esverdeado escuro para o conteúdo branco cria um respiro visual embutido pelo contraste, não só pelo espaço.
  • Seções escuras generosas: as áreas escuras de hero e de recursos usam padding vertical extra (80px+) para deixar o fundo escuro de floresta respirar.
  • Seções claras compactas: as áreas de conteúdo brancas são mais densas, com grades de cards mais justas e menos espaçamento vertical.

Escala de raios de borda

  • Mínimo (1px–2px): spans pequenos, badges
  • Sutil (4px): campos, botões pequenos
  • Padrão (8px): cards, links
  • Card (16px): cards padrão, contêineres
  • Alternador (20px): elementos de switch
  • Grande (24px): painéis grandes
  • Imagem (30px–32px): contêineres de imagem
  • Hero (48px): cards do hero
  • Pílula (100px–999px): botões, pílulas de navegação
  • Completo (9999px): pílula máxima

O que fazer e o que evitar

Faça

  • Use #001e2b (preto de floresta) nas seções escuras — não preto puro
  • Aplique o MongoDB Green (#00ed64) com parcimônia, para o máximo impacto elétrico
  • Use a MongoDB Value Serif SÓ nos títulos de hero/display — Euclid Circular A para todo o resto
  • Aplique a Source Code Pro em caixa-alta com tracking largo (1px–3px) nos rótulos técnicos
  • Use sombras tingidas de azul-esverdeado (rgba(0,30,43,0.12)) na elevação principal dos cards
  • Mantenha a dualidade de seções escuras/claras — contraste dramático entre os modos
  • Use peso 300 no texto de corpo — o peso leve é a voz de leitura
  • Aplique raio de pílula (100px) nos botões de ação principal

Não faça

  • Não use preto puro (#000000) em fundos escuros — use sempre o preto-azulado (#001e2b)
  • Não use o MongoDB Green (#00ed64) em fundos — ele é um destaque para texto, sublinhados e pequenos realces
  • Não use sombras cinza padrão — use sempre as tingidas de azul-esverdeado (rgba(0,30,43,...))
  • Não aplique a fonte serifada no texto de corpo — a MongoDB Value Serif é só para o hero
  • Não use espaçamento entre letras estreito nos rótulos em Source Code Pro — o tracking largo É a identidade
  • Não misture tratamentos de seção escura e clara na mesma seção
  • Não use cores quentes — a paleta é estritamente fria (azul-esverdeado, verde, azul)
  • Não se esqueça dos sublinhados de destaque em verde — são o elemento decorativo característico

Guia de iteração

  1. Comece pela decisão de modo: escuro (#001e2b) para hero/recursos, branco para conteúdo
  2. O MongoDB Green (#00ed64) é elétrico — use uma vez por seção para o máximo impacto
  3. Os títulos serifados (MongoDB Value Serif) criam a autoridade editorial — nunca use no corpo
  4. O texto de corpo em peso 300 cria a experiência de leitura arejada — não caia no 400 por padrão
  5. Source Code Pro em caixa-alta com tracking largo nos rótulos técnicos — a voz do banco de dados
  6. As sombras tingidas de azul-esverdeado mantêm tudo no mundo de cores do MongoDB
