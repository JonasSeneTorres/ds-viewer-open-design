Monitoramento de erros. Dashboard escuro, denso em dados, destaque rosa-arroxeado.

Tema visual e atmosfera

O site da Sentry é uma interface de ferramenta de desenvolvedor pensada primeiro para o modo escuro, que fala a língua dos editores de código e das janelas de terminal. Toda a estética se enraíza em fundos preto-arroxeados profundos (#1f1633, #150f23) que evocam as madrugadas de depuração para as quais a Sentry foi criada. Sobre essa tela de tinta, um conjunto cuidadosamente escolhido de roxos, rosas e um destaque verde-limão característico (#c2ef4e) cria um sistema visual que parece, ao mesmo tempo, técnico e vibrante.

A combinação tipográfica é deliberada: a "Dammit Sans" aparece em escala de hero (88px, peso 700) como uma fonte de display com personalidade e atitude, que combina com a voz irreverente da marca ("Code breaks. Fix it faster."), enquanto a Rubik é a fonte de interface que faz o trabalho pesado em todo texto funcional — títulos, corpo, botões, legendas e navegação. A Monaco fornece a camada monoespaçada para trechos de código e conteúdo técnico, completando a trindade das ferramentas de desenvolvedor.

O que torna a Sentry distinta é abraçar a estética de "IDE escura" sem parecer fria ou estéril. Tons de roxo quentes substituem os cinzas frios típicos das ferramentas de desenvolvedor, e elementos ilustrativos ousados (personagens 3D, capturas do produto coloridas) pontuam a tela escura. O sistema de botões usa um roxo apagado característico (#79628c) com sombras internas que criam uma qualidade tátil, quase física — os botões parecem poder ser pressionados para dentro da superfície.

Características principais:

  • Fundos preto-arroxeados escuros (#1f1633, #150f23) — nunca preto puro
  • Espectro de destaques em roxo quente: do profundo (#362d59), passando pelo médio (#79628c, #6a5fc1), até o vibrante (#422082)
  • Destaque verde-limão (#c2ef4e) para CTAs e realces de alta visibilidade
  • Destaques rosa/coral (#ffb287, #fa7faa) para estados de foco e realces secundários
  • Fonte de display "Dammit Sans" para a personalidade da marca em escala de hero
  • Rubik como fonte principal da interface, com rótulos em caixa-alta e espaçamento entre letras
  • Monaco monoespaçada nos elementos de código
  • Sombras internas nos botões criando profundidade tátil
  • Efeitos de vidro fosco com blur(18px) saturate(180%)

Princípios

  • Dupla personalidade: a Dammit Sans traz o caráter irreverente da marca na escala de display; a Rubik dá um profissionalismo limpo a tudo que é funcional.
  • Caixa-alta como sistema: botões, legendas, rótulos e microtextos usam text-transform: uppercase com espaçamento entre letras sutil (0.2px–0.25px), criando um padrão sistemático de "rótulo técnico" em todo lugar.
  • Estratificação de pesos: a Rubik usa 400 (corpo), 500 (ênfase/navegação), 600 (títulos/forte), 700 (botões/CTAs) — um sistema limpo de pesos em quatro níveis.
  • Títulos justos, corpo relaxado: todos os títulos usam altura de linha de 1.10–1.25; o corpo usa 1.50; as legendas pequenas se expandem para 2.00, para a legibilidade em tamanhos minúsculos.

Filosofia do espaço em branco

  • Respiro escuro: espaçamento vertical generoso entre as seções (64px–80px+) deixa o fundo escuro funcionar como descanso visual.

  • Padding assimétrico: os botões usam padrões de padding assimétricos (12px 16px, 8px 12px) que parecem orgânicos em vez de rígidos.

Filosofia das sombras: a Sentry usa uma combinação única de sombras internas (os botões parecem pressionados PARA DENTRO da superfície) e brilhos ambientes (o conteúdo irradia do fundo escuro). A sombra ambiente em roxo profundo (rgba(22, 15, 36, 0.9)) é a assinatura — cria uma qualidade bioluminescente, em que o conteúdo parece emitir sua própria luz tingida de roxo.

O que fazer e o que evitar

Faça

  • Use fundos em roxo profundo (#1f1633, #150f23) — nunca preto puro (#000000)
  • Aplique sombras internas nos botões primários, para o efeito tátil de pressionado
  • Use a Dammit Sans SÓ nos títulos de hero/display — Rubik para todo o resto
  • Aplique text-transform: uppercase com letter-spacing: 0.2px em botões e rótulos
  • Use o destaque verde-limão (#c2ef4e) com parcimônia, para o máximo impacto
  • Use efeitos de vidro fosco (blur(18px) saturate(180%)) nas superfícies em camadas
  • Mantenha os tons de sombra roxos e quentes — as sombras devem parecer tingidas de roxo, não cinza neutro
  • Use o sistema de quatro pesos da Rubik: 400 (corpo), 500 (navegação/ênfase), 600 (títulos), 700 (CTAs)

Não faça

  • Não use preto puro (#000000) nos fundos — use sempre os pretos-arroxeados quentes
  • Não aplique a Dammit Sans no texto de corpo ou em elementos de interface — ela é só de display
  • Não use cinza padrão (#666, #999) nas bordas — use cinzas tingidos de roxo (#362d59, #584674)
  • Não abandone o tratamento em caixa-alta dos botões — é um padrão de todo o sistema
  • Não use cantos vivos (raio de 0px) — mínimo de 6px em todos os elementos interativos
  • Não misture o destaque verde-limão com os destaques coral/rosa no mesmo componente
  • Não use sombras planas (sem inset) nos botões primários — a qualidade tátil é característica
  • Não se esqueça do espaçamento entre letras no texto em caixa-alta — 0.2px no mínimo

Guia de iteração

  1. Comece sempre pelo fundo roxo-escuro — a paleta de cores é construída PARA o modo escuro
  2. Use sombras internas nos botões e brilhos ambientes roxos nas seções hero
  3. Caixa-alta + espaçamento entre letras é o padrão sistemático para rótulos, botões e legendas
  4. O verde-limão (#c2ef4e) é a cor de "estalo" — no máximo uma vez por seção
  5. Vidro fosco nos painéis sobrepostos, roxo sólido nas superfícies principais
  6. A Rubik cuida de 90% da tipografia — a Dammit Sans é só para o hero
