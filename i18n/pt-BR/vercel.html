Tema visual e atmosfera

O site da Vercel é a tese visual de uma infraestrutura de desenvolvimento que se torna invisível — um design system tão contido que beira o filosófico. A página é predominantemente branca (#ffffff) com texto quase preto (#171717), criando um vazio de galeria em que cada elemento precisa justificar cada pixel. Não é minimalismo como decoração; é minimalismo como princípio de engenharia. O design system Geist trata a interface como um compilador trata o código — todo token desnecessário é removido até restar apenas a estrutura.

A família tipográfica própria Geist é a joia da coroa. A Geist Sans usa espaçamento entre letras fortemente negativo (-2.4px a -2.88px nos tamanhos de display), criando títulos que parecem comprimidos, urgentes e projetados — como código minificado para produção. Nos tamanhos de corpo, o tracking relaxa, mas a precisão geométrica permanece. A Geist Mono completa o sistema como companheira monoespaçada para código, saída de terminal e rótulos técnicos. As duas fontes ativam o recurso OpenType "liga" (ligaduras) globalmente, acrescentando uma camada de sofisticação tipográfica que recompensa a leitura atenta.

O que distingue a Vercel de outros design systems monocromáticos é a filosofia da sombra como borda. Em vez de bordas CSS tradicionais, a Vercel usa box-shadow: 0px 0px 0px 1px rgba(0,0,0,0.08) — uma sombra sem deslocamento, sem desfoque e com 1px de expansão, que cria uma linha parecida com borda sem as implicações do box model. Essa técnica permite que as bordas existam na camada de sombra, possibilitando transições mais suaves, cantos arredondados sem recorte e um peso visual mais sutil que o das bordas tradicionais. Todo o sistema de profundidade é construído sobre pilhas de sombras com múltiplos valores, em que cada camada tem uma função específica: uma para a borda, uma para a elevação suave e uma para a profundidade ambiente.

Características principais:

  • Geist Sans com espaçamento entre letras extremamente negativo (-2.4px a -2.88px no display) — texto como infraestrutura comprimida
  • Geist Mono para código e rótulos técnicos, com OpenType "liga" ativado globalmente
  • Técnica de sombra como borda: box-shadow 0px 0px 0px 1px substitui as bordas tradicionais em todo o sistema
  • Pilhas de sombras em várias camadas para uma profundidade sutil (borda + elevação + ambiente em uma única declaração)
  • Tela quase branca pura com texto #171717 — não exatamente preto, criando uma suavidade de microcontraste
  • Cores de destaque específicas de cada etapa do fluxo: Ship Red (#ff5b4f), Preview Pink (#de1d8d), Develop Blue (#0a72ef)
  • Sistema de anel de foco usando hsla(212, 100%, 48%, 1) — um azul saturado para acessibilidade
  • Badges em pílula (9999px) com fundos tingidos para indicadores de status

Princípios

  • Compressão como identidade: nos tamanhos de display, a Geist Sans usa -2.4px a -2.88px de espaçamento entre letras — o tracking negativo mais agressivo entre os grandes design systems. Isso cria um texto que parece minificado, como código otimizado para produção. O tracking relaxa progressivamente conforme o tamanho diminui: -1.28px em 32px, -0.96px em 24px, -0.32px em 16px e normal em 14px.
  • Ligaduras em todo lugar: todo elemento de texto Geist ativa o OpenType "liga". As ligaduras não são decorativas — são estruturais, criando combinações de glifos mais justas e eficientes.
  • Três pesos, papéis rígidos: 400 (corpo/leitura), 500 (interface/interação), 600 (títulos/ênfase). Nada de negrito (700), exceto em microbadges. Essa faixa estreita de pesos cria hierarquia por tamanho e tracking, não por peso.
  • Mono como identidade: a Geist Mono em caixa-alta com "tnum" ou "liga" funciona como a voz de "console do desenvolvedor" — rótulos técnicos compactos que conectam o site de marketing ao produto.

Princípios de layout

Sistema de espaçamento

  • Unidade base: 8px
  • Escala: 1px, 2px, 3px, 4px, 5px, 6px, 8px, 10px, 12px, 14px, 16px, 32px, 36px, 40px
  • Salto notável: de 16px direto para 32px — não há 20px nem 24px na escala principal

Grid e contêiner

  • Largura máxima do conteúdo: aproximadamente 1200px
  • Hero: coluna única centralizada com padding superior generoso
  • Seções de recursos: grids de 2–3 colunas para cards
  • Divisores de largura total usando border-bottom: 1px solid #171717
  • Capturas de código/dashboard em largura total ou contidas com borda

Filosofia do espaço em branco

  • Vazio de galeria: padding vertical enorme entre seções (80px–120px+). O espaço em branco É o design — comunica que a Vercel não tem nada a provar nem a esconder.
  • Texto comprimido, espaço expandido: o espaçamento negativo agressivo dos títulos é contrabalançado por um espaço em branco generoso ao redor. O texto é denso; o espaço ao redor dele é vasto.
  • Ritmo das seções: seções brancas alternam com seções brancas — não há variação de cor entre elas. A separação vem apenas das bordas (bordas por sombra) e do espaçamento.

Escala de raios de borda

  • Micro (2px): trechos de código inline, spans pequenos
  • Sutil (4px): contêineres pequenos
  • Padrão (6px): botões, links, elementos funcionais
  • Confortável (8px): cards, itens de lista
  • Imagem (12px): cards em destaque, contêineres de imagem (arredondados no topo)
  • Grande (64px): pílulas de navegação por abas
  • XL (100px): links grandes de navegação
  • Pílula completa (9999px): badges, pílulas de status, tags
  • Círculo (50%): botão de menu, contêineres de avatar

Filosofia das sombras: a Vercel tem possivelmente o sistema de sombras mais sofisticado do web design moderno. Em vez de usar sombras para elevação no sentido tradicional do Material Design, a Vercel usa pilhas de sombras com vários valores, em que cada camada tem um propósito arquitetônico distinto: uma cria a "borda" (0px de expansão, 1px), outra adiciona suavidade ambiente (2px de desfoque), outra cuida da profundidade à distância (8px de desfoque com expansão negativa) e um anel interno (#fafafa) cria o realce sutil que faz o card "brilhar" por dentro. Essa abordagem em camadas faz os cards parecerem construídos, não flutuantes.

Profundidade decorativa

  • Gradiente do hero: lavagem suave de gradiente multicolorido em tons pastel atrás do conteúdo do hero (quase invisível, atmosférico)
  • Bordas de seção: 1px solid #171717 (linha escura completa) entre as seções principais
  • Sem variação de cor de fundo — a profundidade vem inteiramente das camadas de sombra e do contraste das bordas

O que fazer e o que evitar

Faça

  • Use a Geist Sans com espaçamento entre letras fortemente negativo nos tamanhos de display (-2.4px a -2.88px em 48px)
  • Use sombra como borda (0px 0px 0px 1px rgba(0,0,0,0.08)) em vez de bordas CSS tradicionais
  • Ative "liga" em todo texto Geist — as ligaduras são estruturais, não opcionais
  • Use o sistema de três pesos: 400 (corpo), 500 (interface), 600 (títulos)
  • Aplique as cores de destaque do fluxo (vermelho/rosa/azul) apenas no contexto do fluxo
  • Use pilhas de sombras em várias camadas nos cards (borda + elevação + ambiente + realce interno)
  • Mantenha a paleta acromática — os cinzas de #171717 a #ffffff são o sistema
  • Use #171717 em vez de #000000 no texto principal — o microcalor faz diferença

Não faça

  • Não use espaçamento entre letras positivo na Geist Sans — ele é sempre negativo ou zero
  • Não use peso 700 (negrito) no texto de corpo — 600 é o máximo, e só em títulos
  • Não use border CSS tradicional em cards — use a técnica de borda por sombra
  • Não introduza cores quentes (laranjas, amarelos, verdes) na estrutura da interface
  • Não aplique as cores de destaque do fluxo (Ship Red, Preview Pink, Develop Blue) de forma decorativa
  • Não use sombras pesadas (opacidade > 0.1) — o sistema de sombras é quase um sussurro
  • Não aumente o espaçamento entre letras do texto de corpo — a Geist foi feita para rodar justa
  • Não use raio de pílula (9999px) em botões de ação principal — pílulas são só para badges/tags
  • Não omita o anel interno #fafafa nas sombras dos cards — é o brilho que faz o sistema funcionar

Guia de iteração

  1. Sempre use sombra como borda em vez de borda CSS — 0px 0px 0px 1px rgba(0,0,0,0.08) é a base
  2. O espaçamento entre letras acompanha o tamanho da fonte: -2.4px em 48px, -1.28px em 32px, -0.96px em 24px, normal em 14px
  3. Apenas três pesos: 400 (ler), 500 (interagir), 600 (anunciar)
  4. A cor é funcional, nunca decorativa — as cores do fluxo (vermelho/rosa/azul) marcam só as etapas do pipeline
  5. O anel interno #fafafa nas sombras dos cards é o que dá aos cards da Vercel seu brilho interno sutil
  6. Geist Mono em caixa-alta para rótulos técnicos, Geist Sans para todo o resto
